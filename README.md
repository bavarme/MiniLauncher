# Cinema OS

Лаунчер для Android TV / Google TV в стиле tvOS: главный экран с обоями, карусель приложений, поиск с экранной клавиатурой, настройки и заставка. Без рекламы, без виджетов и без интернета.

## Сборка без своего компьютера

1. Откройте вкладку **Actions** репозитория и выберите запуск **Build APK** (нужный коммит или ветка).
2. Внизу страницы запуска скачайте артефакт **MiniLauncher-debug-apk**. Внутри файл `app-debug.apk`.
3. Если сборка упала, артефакт **build-log** содержит полный лог Gradle, а на странице запуска выводятся первые ошибки компиляции.

Сборка запускается сама при каждом push и вручную через «Run workflow».

## Установка

1. Скопируйте `app-debug.apk` на телевизор (флешка, файловый менеджер, приложение для загрузки файлов) и установите. Разрешите установку из неизвестных источников, если система попросит.
   Через компьютер в одной сети: `adb connect IP_ТЕЛЕВИЗОРА:5555` и `adb install -r app-debug.apk`.
2. Сделайте лаунчер главным: нажмите кнопку «Домой» на пульте, выберите **Cinema OS** и нажмите **Всегда**.
   Либо: Настройки → Приложения → Приложения по умолчанию → Главный экран.

## Откат

- Нажмите «Домой», выберите прежний лаунчер (например, Google TV) и нажмите **Всегда**.
- Или удалите приложение: Настройки → Приложения → Cinema OS → Удалить. Пакет: `com.example.minilauncher`.
- Настройки самого лаунчера сбрасываются кнопкой «Сбросить настройки лаунчера» в разделе «Система».

## Управление пультом

- **OK** на плитке: открыть приложение.
- **Меню**: меню приложения, на котором стоит фокус (избранное, перемещение, скрыть, сведения). Если приложение ещё не выбрано, открываются настройки.
- **Назад**: закрыть поиск, настройки или меню. На главном экране не делает ничего, лаунчер не закрывается.
- **Любая кнопка** во время заставки: выключает её.

## Что есть

- **Главный экран**: приветствие, часы, дата, индикатор сети (Wi-Fi, Ethernet или «Сеть»), кнопки «Поиск» и «Настройки».
- **Обои**: 12 встроенных фотографий, плавная смена по таймеру (15 с, 30 с, 1 мин или 5 мин), медленное приближение. Авторы и лицензии: `WALLPAPER-CREDITS.md`.
- **Карусель приложений**: все приложения для ТВ (с Leanback-запуском). Порядок меняется в настройках или через меню, приложения можно скрыть, отмечать звёздочкой как избранные. Список обновляется сам при установке, удалении и обновлении приложений.
- **Поиск**: экранная клавиатура RU / EN / цифры, фильтр по названию, история последних запросов (хранятся последние 8).
- **Настройки**, пять разделов: Приложения, Оформление, Заставка, Поиск, Система. Каждое изменение сохраняется сразу. Сброс настроек требует двойного нажатия.
- **Заставка**: через 2, 5, 10 или 30 минут простоя показывает обои по кругу, при желании с часами. Выключается в настройках.
- **Уменьшить движение**: отключает масштабирование и смещение плиток, а также анимацию обоев.
- **Масштаб**: вёрстка рассчитана на ширину 1920 dp и масштабируется пропорционально ширине экрана (от 0,5× до 3×).

Начальный порядок приложений задаётся в `app/src/main/res/values/config.xml` (массив `dock_apps`).

## Чего пока нет

Из исходной спецификации не реализовано (и не скрыто под видом готового):

- Центр управления (быстрые настройки), локальные фото и видео, профили пользователей.
- Строки контента, блок «Недавние», погода, голосовой поиск.
- Отдельная полоса «Избранное» на главном экране. Избранное отмечается звёздочкой в карусели.
- Блок с отдельным «featured»-приложением. Верхняя часть главного экрана показывает приветствие, часы и кнопки.
- Хранение настроек на DataStore. Используется SharedPreferences: одной зависимостью меньше.
- Автоматические тесты (unit и UI). Их в проекте пока нет.

Имя в приветствии задано константой `USER_NAME` в `Hero.kt`. Замените на своё.

## Проверка

- Сборка выполняется в GitHub Actions при каждом push. Результат каждого запуска виден на вкладке Actions.
- Запуск на реальном Android TV и в эмуляторе **не проводился**. Фокус пульта, заставка, кнопка «Меню» и возврат из других приложений проверены только чтением кода.
- Автотестов нет, поэтому ни один тест в этом репозитории не запускался.

## Структура

- `MainActivity.kt`: кнопки пульта, заставка по простою, обновление списка при установке приложений.
- `LauncherScreen.kt`: главный экран и переключение оверлеев (поиск, настройки, меню).
- `LauncherState.kt`: общее состояние экрана. `AppPrefs.kt`: сохранение настроек.
- `AppRepository.kt`: поиск приложений для ТВ и порядок карусели.
- `Hero.kt`, `Dock.kt`, `AppTile.kt`, `Background.kt`: главный экран. `Settings.kt`, `Search.kt`, `ContextMenu.kt`, `ScreenSaver.kt`: оверлеи и заставка.
- `Ui.kt`: масштаб и токены дизайна (цвета, отступы, длительности анимаций). `Components.kt`: кнопки и клавиши.
